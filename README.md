# ace

Стенд методов обучения в контексте (ACE, Dynamic Cheatsheet, SCOPE, TF-GRPO, EvoLib, GEPA, MCE). Верность методов
апстримам проверяется живыми записями: апстрим запускается как есть, прокси пишет журнал запросов к модели, порт
метода проигрывает тот же журнал.

| где | что |
|---|---|
| `records/<запись>/` | раннер записи апстрима (`run.sh`, `run.json`) и сама запись (`rec.jsonl`, вывод апстрима) |
| `records/setup_envs.sh` | окружения апстримов для записей |
| `tools/record/` | прокси записи и воспроизведения (`record.py`), эмбеддинги (`embeddings.py`) |
| `tests/test_record.py` | тест прокси |
