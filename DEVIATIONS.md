# Отклонения

Каждое расхождение нового кода со старым (тег `pre-rewrite`) и с апстримами — с причиной. Тесты-мостик
нормализуют только то, что записано здесь.

## Регрессия промптов: новый код против старого

Проверка: `uv run python tools/trace.py /tmp/t.json && uv run python tools/compare.py tools/ref_variants.json /tmp/t.json`.
Эталоны: `tools/ref_trace.json` — 25 методов старого кода; `tools/ref_variants.json` — варианты ACE старого
кода под новыми именами (`tools/ref_variants.py`): новый `ace` = старый `swap(ace, curate=curate_json)`,
`ace_text` = `swap(ace, curate=curate_json, reflect=reflect_text)`, `ace_rewrite` = `swap(ace, curate=curate_rewrite)`.

| метод | итог |
|---|---|
| baseline, ace_exact, ace_exact_dedup | совпадают с `ref_trace.json` и `ref_variants.json` |
| ace, ace_text | совпадают с `ref_variants.json` |
| ace_rewrite | расходится (п. 1): с 7-го вызова другие id, дальше фиктивная модель отвечает иначе (ответ — хэш промпта) |
| ace против `ref_trace.json` | расходится с первого вызова куратора (п. 3) |

## Методы

1. **ace_rewrite: перезапись памяти — новая запись.** Было: если в памяти ровно одна запись, куратор правил
   её текст, сохраняя id и счётчики (`[r1]` во всех промптах); иначе старые удалялись. Стало: все старые
   пункты уходят со статистикой, новый — с новым id и нулевыми счётчиками. Причина: статистика принадлежит
   неизменяемому тексту, правка текста — новая запись (REVIEW.md, «Уроки и файлы»).
2. **Куратор стенда: UPDATE — новый пункт.** Было: UPDATE менял текст пункта, id и счётчики оставались.
   Стало: новый пункт на месте старого, новый id, счётчики с нуля. Причина та же. Фиктивная модель UPDATE
   не выдаёт, трасса не видит.
3. **База цепочки `ace` — куратор операциями одной схемой**, а не агент с файловыми инструментами над
   пунктами со счётчиками. Причина: файловый куратор над записями со статистикой — запрещённая смесь двух
   миров памяти (REVIEW.md, «Решено: вариант 1»). Файловый куратор над уроками убран совсем.
4. **ace_text: память без счётчиков и отсева.** Свободный текст меток не даёт, а память со счётчиками их
   требует — стык не соберётся. Раньше счётчики были, но в них ничего не приходило, отсев не срабатывал:
   поведение то же.
5. **ace_exact_dedup: слитый пункт — новая запись** с новым id на месте первого (было: id первого).
   Счётчики — как вернула модель (сумма по группе), как в апстриме (BulletpointAnalyzer). Промпт слияния
   по-прежнему просит id первого — он нужен только для разбора ответа. Фиктивная модель слияний не даёт.

## Цикл и протокол

6. **val оценивает всю группу попыток** с выбором в зачёт, как тест (было: одна попытка при T=0). Причина:
   val и тест меряют одно и то же. У портированных методов попытка одна — без разницы.
7. **Вердикт попытки ставится сразу после попытки** (было: после всех попыток группы). Причина: масштабы не
   смешиваются, `on_attempt` видит вердикт. Для `judge` меняется порядок вызовов (у evolib_judge судья
   пойдёт между попытками) — записать при портировании EvoLib.
8. **Самоотчёт USED разбирает извлечение ACE**, а строку USED в системный промпт ставит показ ace_exact
   (было: сигнал `usage="self"` в цикле). Поведение то же. В логе поля `reported` больше нет; прочитанное
   инструментами — `read`, как раньше.
9. **Срок жизни «задача» ушёл из цикла** (`memory.new_task()`): записи, живущие попытку или вопрос
   (tactical SCOPE), сбрасывает сам метод.
10. **Шаговый режим модели** включается, когда у ученика показ смотрит шаги (`watches_steps`) и есть
    инструменты (было: событие шага обновления или хук инжекта). Для ACE и baseline шагов нет.
11. **memory.json**: `kind` — имя контейнера (`bullet`), у ace_exact есть `section`; у уроков — журнал
    исходов `outcomes` и счётчики helpful / harmful. Скрытых видов больше нет: что решателю не видно —
    поле метода, а не вид памяти.
12. **Лог по вопросу** дополнен группой попыток (ответы, вердикты, температуры, показанное, прочитанное,
    `fired`, `Patch`-и), способом выбора ответа (`pick`, `pass_at_k`), вердиктом группы (`vote`); `gated` —
    решения Gate на этом вопросе, а не последнее за прогон.
