## COMMON MISTAKES TO AVOID

[err-00001] helpful=0 harmful=0 :: MISTAKE: Treating 'TotalFairValue' tags as dollar amounts. In this taxonomy, 'TotalFairValue' tags (e.g., EquityInstrumentsOtherThanOptionsVestedInPeriodTotalFairValue) represent COUNTS OF SHARES, not dollar amounts. If the entity is a dollar amount (e.g., '$6.5 million of unrecognized compensation cost'), do NOT select a TotalFairValue tag. Always check the entity's data type first.
[err-00005] helpful=0 harmful=0 :: MISTAKE: When two DIFFERENT entities in a sentence share the SAME numeric value (e.g., both are $2.87), do NOT disambiguate tags by assuming one tag applies to one entity and another tag to the other based on arbitrary or assumed conventions. The error occurred because the model conflated a Rights exercise price ($2.87) with a private placement price ($2.87) and assigned the wrong tag to each. Always anchor each tag to the SPECIFIC entity occurrence it describes by reading the surrounding text, not by value alone. Verify each mapping against the actual semantic role of the entity in its sentence.

## CONTEXT CLUES & INDICATORS

[ctx-00002] helpful=1 harmful=0 :: CONTEXT CLUE: The phrase 'unrecognized compensation cost' (or 'compensation cost not yet recognized') is a direct textual match to the tag family EmployeeServiceShareBasedCompensationNonvestedAwardsTotalCompensationCostNotYetRecognized. When this exact phrase appears, prioritize the tag that literally contains 'TotalCompensationCostNotYetRecognized' over semantically similar alternatives like 'fair value of grants'.
[ctx-00006] helpful=0 harmful=0 :: CONTEXT CLUE: When multiple entities share the same numeric value, identify each entity's semantic role from its surrounding text before selecting a tag. For example, 'exercise price of the Rights to purchase common stock' describes a class-of-warrant/right exercise price (map to ClassOfWarrantOrRightExercisePriceOfWarrantsOrRights1), while 'price per share in a private placement' describes a sale-of-stock price (map to SaleOfStockPricePerShare). Even if both values are identical (e.g., both $2.87), they map to DIFFERENT tags because they describe different entities. Anchor each tag to the specific entity occurrence it describes, not to the value.
## OTHERS
[misc-00003] helpful=0 harmful=2 :: DATA-TYPE-FIRST HEURISTIC: Before selecting any XBRL tag, determine the entity's data type: (1) dollar amount -> map to 'CompensationCost'/'Expense' tags; (2) share count -> map to 'TotalFairValue'/'NumberOfShares' tags; (3) time period -> map to 'PeriodForRecognition'/'VestingPeriod' tags. Never assume a dollar amount represents a 'fair value of grants' — verify the data type explicitly.
[misc-00004] helpful=0 harmful=0 :: TIME-PERIOD DISAMBIGUATION: For entities describing how long compensation cost will be recognized (e.g., '2.32 years' weighted-average recognition period), prefer the tag ending in 'PeriodForRecognition' (e.g., ...TotalCompensationCostNotYetRecognizedPeriodForRecognition1) over 'VestingPeriod' tags. 'VestingPeriod' describes the vesting schedule of awards, while 'PeriodForRecognition' describes the expense-recognition timeline — they are distinct concepts even if numerically similar.
