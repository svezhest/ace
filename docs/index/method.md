# Метод целиком: цикл, дерево, замер, слияние

[Корень индекса](../INDEX.md) · задачи — [TASKS](../TASKS.md) · пробы по дням — [lab/INDEX](../lab/INDEX.md)

Цикл NRHSI: узел (`src/`) → замер на M свежих задачах → ревьювер ×S → писатель → кандидат в пул узла → выбор
следующего узла. Роли — в [ревьювер](reviewer.md) и [писатель](writer.md); среда — в [стенд и бенчмарки](bench.md).

## Как пришли к методу (до 29.10)

Подробно — [предыстория](prehistory.md). Решения, из которых собран цикл, по дневнику:
- [10.10](../../../itmo/cs-masters/thesis/diary.html#d2026-10-10) — постановка: 9B сама правит свой контекст, правку принимает A/B, сильной модели в цикле
  нет; «ввод НЕ ДОЛЖЕН ИДТИ ОТ СИЛЬНОЙ МОДЕЛИ -- это грязный путь для диплома» (дневник, «Взгляд изнутри»).
- [11–12.10](../../../itmo/cs-masters/thesis/diary.html#d2026-10-12) — дерево: узел = хэш харнесса, 9B даёт K правок и prior, PUCT, value = k задач по
  1 роллауту; [15.10](../../../itmo/cs-masters/thesis/diary.html#d2026-10-15) отложено созвоном с научником (ниша CONTEXT × AGENTIC, правка только O).
- [20.10](../../../itmo/cs-masters/thesis/diary.html#d2026-10-20) — постановка автора: «для маленьких моделей заливать вход контекстом это почти
  гарантированный минус / при этом еще никто не нашел способа надежно передать уроки в маленькие модели чтобы получить плюс» (дневник,
  «Взгляд изнутри», поворотные точки).
- [21–24.10](../../../itmo/cs-masters/thesis/diary.html#d2026-10-23) — prior Δlog p для PUCT: с исходом не связан → правило «prior только при доказанной
  связи с исходом, иначе равномерный» ([appworld-prior-notes](../../../itmo/cs-masters/thesis/appworld-prior-notes.md)); перезамер лидеров дерева
  v2 — проклятие победителя (+8/20 → +4/40); tree3b остановлен, ходы слепые ([24.10](../../../itmo/cs-masters/thesis/diary.html#d2026-10-24)).
- [27.10](../../../itmo/cs-masters/thesis/diary.html#d2026-10-27) — ядро и оси: замороженная модель — исполнитель и оптимизатор; цикл роллауты →
  исследование → правки → замер на M сэмплах → выбор; «дерево или beam — очередная ось абляции… СЛИВАТЬ ЛИ ИХ». Цена эпизода
  AppWorld: медиана 5.5 мин, 30 задач × 3 сэмпла ≈ 12 ч модели (дневник, 27.10).
- 28.10 — стандартная раскладка src/ и logs/, название NRHSI, новизна в дереве с пулами правок, слиянии узлов и
  сэмплинге трасс (дневник, «Взгляд изнутри», поворотные точки); проект метода —
  [method-project](../../../itmo/cs-masters/thesis/method-project.html).
