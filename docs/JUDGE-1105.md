## Судья v2 (коммит 663fae1, таблица — e157943)
- `nrhsi/editor/judge2.py`: роль `judge` в механике редактора (session/turn/state/phase/tools/schema). Песочница —
  как у писателя с `--rerun` (`work.build_work`: README, logs/ вида, tests/rerun.py, tests/orig_src, smoke), src/ —
  итоговый src правки; из README убрано «This is what you edit.». bash — механика исследователя («/» = корень копии).
- Инструменты: bash (лимит L) и `verdict(why, evidence, verdict ∈ helps | in the way)` — поля в этом порядке.
  После лимита — «You have used all L bash calls… Answer now with verdict, from what you have read.», до 3 ходов.
  L = 0: bash нет вовсе, промпт без репозитория, вердикт — всё равно последним полем.
- Вход: diff (обрезан до 3000, как у v1) + блок места из `rerun.py --contrast` (как у v1) + при L > 0 указатель
  «the log of this run is logs/run_N.jsonl; the line numbers below are its lines». Вопрос — дословно v1, без установки
  на опровержение. Промпт: `python3 -m nrhsi.editor.judge2 dry --limit L --name 01_W1`.
- Seed сессии: sha256(«правка|прогон|сэмпл»), ход — seed + номер хода; от лимита не зависит.
- Проверено на заглушке модели: лимит → финальные ходы только с verdict; bash после лимита не исполняется;
  неверный verdict → ошибка в стандартной форме; L = 0 → bash — unknown tool.
