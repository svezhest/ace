# 12.11 — хронология

[Указатель проб](../INDEX.md) · накануне: [11.11](1111.md)

- 00:1x: автор о таблице ступени 27B NT — «издалека он выглядит хорошо»; очередь повторов [NR](../1111/NR-27b-plain-repeats.md) снята до старта.
- Автор: «какие замеры 9б уже есть? … ты можешь попросить агента сделать каталог ошибок» → [каталог ошибок писателя 9B](../1112/CAT-9b-writer-errors.md) (агент, только чтение).

→ [N08](../1112/N08-27b-on-input-08.md): «27B на входе 08» — верхняя ступень на входе, где у 9B есть сессии обеих веток.
