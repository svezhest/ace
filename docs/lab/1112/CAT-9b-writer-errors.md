**Две меры, которые не смешиваются.**

- L — бюджет bash (обычно 25). Хвост — ходы без bash после конца бюджета: 3; у G4 — 10; у G8 и G9 — 8.
- default — 9B без рассуждения. thinking — 9B с рассуждением (бюджет 2048 токенов).
- Строки проверки по тикету:
  - Ok — «acts differently»;
  - мёртвая — «goes exactly as in the log» в старой формулировке или «this edit has no effect» в новой (с 5059a5d);

- Ok/Ok — последний ответ проверки без единого Failed.
- Точки решения тикета: D1 первое действие, D2 замысел, D3 первая правка, D4 чтение ответа проверки, D5 починка, D6 сдача.

## 2. Механический слой

### Определения

- **Без применённых правок** — ни один вызов edit не прошёл.
- **Поздняя первая правка** — первая попытка edit сделана, когда bash уже вызван не меньше L−1 раз. Знаменатель — сессии с попыткой правки. GC и GF (L=3) исключены. В П4 исключены продолжения PKR: их логи начинаются с хода 17–20.
- **Правка после конца bash** — попытка edit, сделанная, когда бюджет bash исчерпан. Считается от всех попыток.
- **bash после конца** — вызов bash, отклонённый стендом, потому что бюджет исчерпан. Знаменатель — сессии, дошедшие до лимита.
- **Итог по тикету** — последний блок «Check against the observation» в сессии.
- **old=new с проверочным словом** — отказ «old=new», когда в тексте хода или в последних 1500 знаках рассуждения есть verify, see, read, check, view, show, inspect или look.
- **Недоверие прибору** — шаблон по фразам «stale», «display artifact», «heuristic», «inaccurate», «different file path» и подобным. Это нижняя граница.
- **Повтор** — флаг стенда `repeat`: команда уже была, файлы не менялись.
