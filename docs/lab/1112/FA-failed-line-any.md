# FA — строка Failed для условия внутри `any(...)`: счёт по частям

[Указатель проб](../INDEX.md) · хронология: [12.11](../days/1112.md) · повод: [CK](CK-check-keep-passed.md), [FL](../1111/FL-failed-line-parts.md)

- **Повод.** В [CK](CK-check-keep-passed.md) докат r0 дважды написал верный замысел — «тот же код и тот же вывод» — как
  `any(s.code == code and s.output == steps[-1].output for s in recent)`: вывод сравнён с выводом соседнего шага
  чередования, условие не истинно ни разу. Строка Failed показала хвост списка `recent` и последний элемент, но не
  сказала, какая половина ложна; писатель оба раза вернулся к широкому варианту (качели «мёртвое ↔ широкое»). Та же
  ошибка на один индекс — в `01_plain27_s1` (T=0) и в мёртвом коде `t2_plain27t_s1`. [FL](../1111/FL-failed-line-parts.md)
  (части цепочки `and` на верхнем уровне) мерилась одной попыткой при T=0 — тогда ступень шла жадным декодированием.
- **Что сделано (ветка `feature/failed-line-any`, 6fb922a = `feature/check-keep-passed` + правка FL + `gate._any_parts`).**
  Для `any(A and B for x in X)`, ни разу не истинного: «of the 9 items of `recent`, `s.code == code` was true for 5,
  `s.output == steps[-1].output` was true for 4, and never both for the same item; … at the first item where
  `s.code == code` was true: `s.output` = '{…album…}', `steps[-1].output` = '2\n'». Оценок нет, только счёт и значения.
  Сверка без модели: проигрыш `t1_ck_r0`, ход 26.
- **Гипотеза.** Увидев, что на элементе с тем же кодом сравниваются вывод альбома и «2», писатель исправит сравнение
  (вывод с выводом того же шага), а не вернётся к широкому условию.
- **Мерка.** Докаты `runs/ck_1112/logs/t1_ck_r0.jsonl` с хода 27, по три на плечо (`probes/1112/fa_roll.sh`): проба —
  ветка `feature/failed-line-any`, база — `feature/check-keep-passed`. 27B NT, T=0,6, лимит bash прежний (в точке
  развилки bash кончился: остались ходы хвоста). Считаю докаты, где итоговый `src/` меняет run 1 и не задевает
  удачные.
- **Ожидание (записано до запуска, 03:46 по `date`).** Проба: чисто не меньше чем в 2 из 3. База: 0–1 из 3 (записанное
  продолжение вернулось к широкому). Не сбылось, если проба не лучше базы.
