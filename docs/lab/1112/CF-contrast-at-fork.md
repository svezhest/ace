# CF — контраст во входе на развилке первой правки, по 10 ответов

[Указатель проб](../INDEX.md) · хронология: [12.11](../days/1112.md) · повод: [CI](CI-contrast-in-input.md)

- **Повод.** Все ночные пробы мерились тремя сессиями или докатами на плечо, и все дали «чисто 1–2 из 3»: на таком
  числе плечи неразличимы. [CI](CI-contrast-in-input.md): с разделом «Passed runs» во входе первая правка не задевает
  8 и 20 в 1 из 3 (в базе 0 из 3) — это может быть и эффект, и разброс. Тикет писателя для таких вопросов велит мерить
  развилкой: один префикс, много ответов на один ход.
- **Что сделано.** Кода нет. `probes/1112/cf_roll.sh`: развилка на ходу 24 сессии `t1_plain27t_s1` (её первая правка,
  23 вызова bash позади), по 10 ответов, до ответа проверки на правку. Плечо base — история как записана. Плечо blk —
  та же история, но в первом сообщении после наблюдения стоит раздел «Passed runs» (`roll.py --sub`).
- **Гипотеза.** С шагами run 8 и 20 во входе первая правка чаще пишется так, что удачные не задеты.
- **Мерка.** По ответу проверки на первую правку каждого ответа: сколько из 10 меняют run 1 и не меняют удачные
  (строка «N runs replayed … K passed runs»). Глазами — что за условие.
- **Ожидание (записано до запуска, 10:06 по `date`).** base: 0–2 из 10 (в трёх сессиях 0 из 3). blk: не меньше 5 из 10
  (K1c на 9B с рассуждением — 4–5 из 10). Не сбылось, если blk не больше base + 2.
- **Оговорка до запуска.** Гибрид: чтение в префиксе шло по входу без раздела (на run 8 и 20 писатель смотрел 2 раза
  из 23 вызовов). Это мерка «раздел перед глазами в момент правки», а не целой сессии с ним.
