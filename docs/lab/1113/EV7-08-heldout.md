  полного вида alf_r1 (40 прогонов) говорит «Ok» на 19: меняют run 40, удачные не трогают, не падают. Классы по моей
  разметке: A 15, M 3, спорная 1.
- **Слепая разметка (13.11, 03:42 по `date`).** Независимый агент, без моих меток, по тем же блочным входам
  (`--blocks`, кэш `inputs_blocks/`) и с доступом к полным логам. Ключ — `08_blind_key.json`, метки —
  `08_blind_labels.json` (178 тыс. токенов). Итог: 15 Ok, 4 Failed, 0 unclear.
  - Failed: E02 и E17 (мои M) — подсказка за 1–2 шага до лимита во всех прогонах, упёршихся в лимит, в том числе в
    run 24, где модель методично открывает новые шкафы. E11 и E13 (мои A) — проверка чередования сравнивает только

    среды; на call 33 модель сковороду берёт.

    после трёх одинаковых пар; агент сам называет решение спорным).
