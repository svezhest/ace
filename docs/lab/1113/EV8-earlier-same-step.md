# EV8 — оценщик: в блоке прогона — на каких вызовах раньше был тот же код

[Указатель проб](../INDEX.md) · хронология: [13.11](../days/1113.md) · прежние пробы: [EV6](EV6-nt-answer-form.md),
[EV7](EV7-08-heldout.md)

- **Повод.** Все ложные «Failed» лучшего варианта на t1 — и у NT (4184e8, 79968d), и у T (4184e8, 95693d, 79968d) —
  решены по run 9, вызовы 19–21 (EV6, EV7). Обоснования: «a repeated API-doc call … not the A/B loop described …
  followed in the log by a new productive step». В логе run 9 модель после блока прежней защиты на вызове 12 начинает
  задачу заново: вызовы 13–19 повторяют 1–9, и `show_api_doc(... show_received_payment_requests)` на вызове 19 —
  уже четвёртый (9, 11, 12, 19). Окно блока — вызовы 14–19, прежних трёх раз в нём нет, и шаг выглядит первым.
  Сообщение правки «You have already run this exact code twice» есть, но где были эти два раза, вход не говорит.
- **Гипотеза.** Ложные «Failed» на run 9 — от окна, а не от суждения модели. Если сказать прямо, на каких вызовах
  раньше в этом прогоне модель прислала тот же код, NT и T увидят цикл.
- **Что поменялось** (`probes/1112/ev_input.py`: `earlier_same`, `run_blocks(earlier=True)`; `ev_judge.py --earlier`).
  После шагов до места в блоке прогона — одна строка: «Earlier in this run, the model sent the same code as at model
  call K−1 at model calls 9, 11, 12.» или «…never sent the same code as at model call K−1.» (для ALFWorld — «action»).
  Сравнение — по коду шага целиком. Больше ничего: блоки EV5b, промпт `runs` (EV6a), `plain27`, T=0. Входы —
  `runs/ev_1112/inputs_blocks_earlier/`; без добавленной строки совпадают с `inputs_blocks/` на всех 40 правках.
- **Риск.** Строка — палка о двух концах. На t1 решающее место многих плохих правок — нормальное перечитывание
  (run 14, вызов 4 — `show_api_descriptions`, как на вызове 1). С пометкой «тот же код, что на вызове 1» его легко
  принять за цикл и пропустить плохую правку. Строка «тот же код на вызове 1» стоит в 15 входах из 40.
- **Набор.** Те же t1 (21) и 08 (19), слепая разметка. Сравнение — с EV6a / EV7 (NT, блоки, строка на прогон): t1 —
  10/11, 2/10, 18; 08 — 3/4, 0/15, 18.
- **Ожидание (13.11, 07:58 по `date`, до запуска).**
  - t1, NT: ложные «Failed» на run 9 уходят хотя бы в одной из 4184e8, 79968d → ложных 0–1. Плохих 8–10: часть
    правок с местом «перечитывание» может уйти в «Ok». Верных 17–20.
  - 08, NT: в пределах шума от 18 (17–19). Чередование в ALFWorld и так видно в окне.
  - Если плохих на t1 меньше 8 — строка толкает к «цикл, значит, правка верна», и в таком виде она вредна.
