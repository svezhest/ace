# Лабораторный журнал: как устроен

До 10.11 журнал вёлся тремя сплошными файлами `docs/LAB-1103.md`, `LAB-1109.md`, `LAB-1110.md` (по 728e61b — 3388,
280 и 844 строки). Здесь тот же текст, разложенный по пробам. Текст перенесён дословно, строка в строку: ничего не
пересказано и не убрано, включая отрицательные итоги и пометки о браке. Нового текста — только заголовки, ссылки и
связки (виды перечислены ниже, их считает проверка).

## Что где

- [INDEX.md](INDEX.md) — указатель: строка на пробу, с гипотезой, статусом, итогом с числом из записи, кодом и данными.
- `1103/`, `1104/`, `1105/`, `1106/`, `1109/`, `1110/` — файлы проб; папка — день постановки. Один файл — одна проба,
  кроме серий, которые журнал сам вёл одной постановкой с общим итогом: W0–W17, блоки ST/C30/AC/RT/SC, блок
  IO/AQ/NV2/TP/BR, TK+TKS, TKC+TKR, H1+H2.
- `days/` — хронология по дням (3.11, 4.11, 5.11, 6.11, 7.11, 9.11, 10.11). Записи дня в порядке журнала. Текст, который
  не относится к одной пробе (ошибки дня, принципы и решения автора, планы, сводки по нескольким пробам, чтение очереди
  целиком), лежит здесь дословно. На месте проб — строка «→ [ID](путь): «заголовок записи»; часть записи / листинг кода».
- [OLD-LINES.md](OLD-LINES.md) — карта «строки старого файла → новый файл». Нужна для ссылок вида «LAB-1103:953–1094»,
  которые остались внутри самого текста журнала и в документах, написанных до разбиения.
- `tools/split.py` — сборщик: таблица «диапазон строк старого файла → проба или день», по ней собраны все файлы.
  `tools/check.py` — проверка переноса.

## Как читать файл пробы

```
# ID — название
[Указатель проб](../INDEX.md) · хронология: [день](../days/MMDD.md) · как устроено — [README](../README.md)

<!-- LAB-1103.md:2905–2916 -->        ← откуда кусок: строки старого файла по 728e61b
...текст журнала дословно...

*Из записи «…» (LAB-1103.md; заголовок и остальное — в X):*   ← кусок чужой записи, относящийся к этой пробе
*[…] строки этой записи между предыдущим куском и этим — в: …*  ← пропуск внутри записи и куда ушли строки

## Код                                  ← листинги «Код пробы» / «Код и запуск» из записей, в конце файла
## Связанные записи                     ← ссылки на места, где о пробе говорится в других файлах
```

Отметка `<!-- … -->` стоит над каждым куском, так что любую строку можно найти в старом файле:
`git show 728e61b:docs/LAB-1103.md | sed -n '2905,2916p'`.

Если кусок касается нескольких проб (общая таблица, сводная строка), он лежит в одном месте, остальные ссылаются на
него в «Связанных записях». Дублей нет — это тоже проверяется.

## Форма новой записи

Новую пробу пишем сразу в свой файл `ДАТА/ID-коротко.md` и добавляем строку в INDEX. Поля по порядку:

- **Гипотеза** — одной фразой, что должно измениться и почему.
- **Пробовали ли** — что в журнале уже было про это (ссылка на файл пробы, не на строку).
- **Изменение и коммит** — что поменяно в коде или во входе; хэш коммита или «кода нет, прототип в …».
- **Мерка** — что и как считаем, кто читает (глазами / прибор).
- **Ожидание до замера** — числа, записанные до первого результата.
- **Итог** — числа и прочитанное; время по `date`.
- **Не проверено** — что не пробовали и чем вывод ограничен.

Время в заголовках — только по `date`; если не снято, так и писать («время не снято `date`»). Ошибки постановки и брак
пишем в ту же запись, отдельным пунктом, не правя старые строки.

Если запись касается дня, а не пробы (решение автора, план, сводка по нескольким пробам), — в `days/MMDD.md`.

## Проверка переноса

Из корня репозитория:

```
python3 docs/lab/tools/check.py
```

Что проверяет: каждая непустая строка старых LAB-1103/1109/1110 (по 728e61b, берутся из git) есть в новых файлах
столько же раз, сколько в старых; ни одна не встречается чаще (дублей нет); всё остальное в новых файлах — только
служебные строки известных видов. INDEX, README, OLD-LINES и `tools/` в сравнение не входят. Код возврата 0 — всё сошлось.

файлов проб вручную `check.py` покажет новые строки в «прочем» — это ожидаемо; сверку переноса стоит запускать
до таких правок или на коммите разбиения.
