# P27 — база писателя на 27B без рассуждения (ступень лестницы)

[Указатель проб](../INDEX.md) · хронология: [11.11](../days/1111.md) · выше по лестнице: [N27](N27-base-27b-thinking.md)

- **Зачем.** Автор, 11.11: «надо отладить методы постепенно повышая тупость модели. 27b T похож на DS NT». Лестница:
  DS T → DS NT ≈ 27B T → 27B NT → 9B T → 9B NT. Здесь — 27B NT: тот же воркер, шлюз 8092 с `GATEWAY_THINKING=off`,
  профиль `stands/plain27.json`, температура 0, одна сессия на вход, каждая читается.
- **База.** develop ca9f523 (сводка повтора явными предложениями, [RL](RL-rerun-log-line.md)), виды `runs/typed_1111`.
- **Входы.** Те же, что на ступени выше: 01, t3, t5. Запуск: `probes/1111/series.sh runs/n27_1111 plain27 1 1 -- 01`,
  `probes/1111/tk27.sh t3 plain27`, `… t5 plain27`.
- **Ожидание (записано после 01, до t3 и t5, 19:12 по `date`).** На t3 и t5 повторится то же, что на 01: bash уйдёт на
  чтение логов, первая правка — после конца bash. Не сбылось, если первая правка раньше 20-го вызова bash.
- **Итог 01 (18:50–19:03, 13,6 мин).** 21 ход, 25 bash, первая правка на ходу 19 — уже без bash; три правки, конец по
  хвосту. Итог сессии — правка без действия (ни один прогон не меняется), проверка Failed / Ok.
  - Ходы 1–18: только чтение, ни одной строки текста и ни одного своего скрипта. Семь вызовов подряд (ходы 12–18) —
    `runs.py show` по страницам: строки 25–57 лога run 1 заняли три вызова, строки 40–94 run 8 — четыре (страница
    8000 знаков — это 11–17 сообщений сырого JSON).
  - Ход 19: условие `code == steps[-2].code and steps[-1].output == steps[-2].output` — сравнены выводы двух разных
    шагов чередования; не истинно никогда. Ход 20: часть про вывод выброшена — задеты удачные 8 и 20 (явная сводка
    это назвала), keep Failed. Ход 21: часть возвращена — снова без действия. Качели «нет действия ↔ широко».
  - У ступени выше (27B T, тот же вход): 20 bash, первая правка на ходу 11, условие проверено своим скриптом по всем
    логам, итог меняет только run 1.
