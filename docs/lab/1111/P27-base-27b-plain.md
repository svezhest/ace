# P27 — база писателя на 27B без рассуждения (ступень лестницы)

[Указатель проб](../INDEX.md) · хронология: [11.11](../days/1111.md) · выше по лестнице: [N27](N27-base-27b-thinking.md)

- **Зачем.** Автор, 11.11: «надо отладить методы постепенно повышая тупость модели. 27b T похож на DS NT». Лестница:
  DS T → DS NT ≈ 27B T → 27B NT → 9B T → 9B NT. Здесь — 27B NT: тот же воркер, шлюз 8092 с `GATEWAY_THINKING=off`,
  профиль `stands/plain27.json`, температура 0, одна сессия на вход, каждая читается.
- **База.** develop ca9f523 (сводка повтора явными предложениями, [RL](RL-rerun-log-line.md)), виды `runs/typed_1111`.
- **Входы.** Те же, что на ступени выше: 01, t3, t5. Запуск: `probes/1111/series.sh runs/n27_1111 plain27 1 1 -- 01`,
  `probes/1111/tk27.sh t3 plain27`, `… t5 plain27`.
- **Ожидание (записано после 01, до t3 и t5, 19:12 по `date`).** На t3 и t5 повторится то же, что на 01: bash уйдёт на
  чтение логов, первая правка — после конца bash. Не сбылось, если первая правка раньше 20-го вызова bash.
- **Итог 01 (18:50–19:03, 13,6 мин).** 21 ход, 25 bash, первая правка на ходу 19 — уже без bash; три правки, конец по
  хвосту. Итог сессии — правка без действия (ни один прогон не меняется), проверка Failed / Ok.
  - Ходы 1–18: только чтение, ни одной строки текста и ни одного своего скрипта. Семь вызовов подряд (ходы 12–18) —
    `runs.py show` по страницам: строки 25–57 лога run 1 заняли три вызова, строки 40–94 run 8 — четыре (страница
    8000 знаков — это 11–17 сообщений сырого JSON).
  - Ход 19: условие `code == steps[-2].code and steps[-1].output == steps[-2].output` — сравнены выводы двух разных
    шагов чередования; не истинно никогда. Ход 20: часть про вывод выброшена — задеты удачные 8 и 20 (явная сводка
    это назвала), keep Failed. Ход 21: часть возвращена — снова без действия. Качели «нет действия ↔ широко».
  - У ступени выше (27B T, тот же вход): 20 bash, первая правка на ходу 11, условие проверено своим скриптом по всем
    логам, итог меняет только run 1.
- **Попутная проба.** [FL](FL-failed-line-parts.md): строка Failed называет ложную часть условия — ход 20 не изменился.
- **Итог t3 (до 19:22, 9,3 мин).** 25 ходов, 25 bash, первая правка на ходу 23 — уже без bash. Ожидание сбылось.
  - Ходы 10–22: тринадцать вызовов подряд `runs.py show 1 NN-MM` окнами по 6 строк лога — одна и та же команда со
    сдвигом диапазона, ни одной строки текста между ними.
  - Ход 23: правка без действия (условие не истинно ни разу). Ход 24: `not_found`. Ход 25: условие
    `len(steps) >= 2 and code == steps[-2].code` — расходятся 2 удачных и 3 проваленных прогона. Конец по хвосту,
    итог сессии задевает 2 удачных.
  - У ступени выше (27B T): первая правка тоже широкая, но после проверки сужена, итог чистый.
- **Итог t5 (до 19:29, 6,7 мин).** 27 ходов, первая правка на ходу 5. Ожидание не сбылось: правка пришла рано.
  - Ход 5: окно 5, как в тикете, — расходятся 2 удачных и 3 проваленных, блок Check — «Ok» четыре раза. Ход 6: смотрит
    шаги run 8 и 20. Ход 7: различитель `recent[0].output.startswith("Execution failed")`, но сообщение стоит в обеих
    ветках — блокируется то же самое. Ход 8: `rerun.py 8`.
  - Ходы 9–25: семнадцать вызовов с hex-дампами кода строк 44 и 49 лога run 8. Страж повторов отвечает «This command
    was already run at tool call 16…», модель меняет диапазон байтов и повторяет. Ходы 26–27 и ещё один — вызовы
    bash, которого в запросе уже нет. Итог сессии — правка хода 7, задевает удачные 8 и 20.
- **Сводка ступени.** Три сессии, три итога хуже ступени выше: 01 — без действия (выше: чисто), t3 — задевает 2 (выше:
  чисто), t5 — задевает 2 (выше: то же). Общее в трёх сессиях — серии однотипных вызовов bash подряд (7, 13, 17) без
  единой строки текста; на них уходит весь лимит, правка или не успевает, или остаётся без проверки. Сужать после
  сводки писатель пробует (01 ход 21, t5 ход 7) — сводку он читает.
- **Чего не пробовали.** Больше одной сессии на вход; температуру выше 0 (у 9B писатель идёт при 0,6, здесь 0 — ступень
  отличается от цели ещё и этим); вход t1, t2, t4, k10. Дальше: [PT](PT-27b-plain-temp06.md).
