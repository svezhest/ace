# P27 — база писателя на 27B без рассуждения (ступень лестницы)

[Указатель проб](../INDEX.md) · хронология: [11.11](../days/1111.md) · выше по лестнице: [N27](N27-base-27b-thinking.md)

- **Зачем.** Автор, 11.11: «надо отладить методы постепенно повышая тупость модели. 27b T похож на DS NT». Лестница:
  DS T → DS NT ≈ 27B T → 27B NT → 9B T → 9B NT. Здесь — 27B NT: тот же воркер, шлюз 8092 с `GATEWAY_THINKING=off`,
  профиль `stands/plain27.json`, температура 0, одна сессия на вход, каждая читается.
- **База.** develop ca9f523 (сводка повтора явными предложениями, [RL](RL-rerun-log-line.md)), виды `runs/typed_1111`.
- **Входы.** Те же, что на ступени выше: 01, t3, t5. Запуск: `probes/1111/series.sh runs/n27_1111 plain27 1 1 -- 01`,
  `probes/1111/tk27.sh t3 plain27`, `… t5 plain27`.

  чтение логов, первая правка — после конца bash. Не сбылось, если первая правка раньше 20-го вызова bash.

    «9B»; и на трёх парных входах итог при этом тот же, что у T, — поздняя правка остаётся симптомом, не причиной.
