  постановке делает то же, что 9B, виновата постановка». Слова автора 11.11: «агента запусти на opus», «запусти опус мы

- **Изменение.** Нет: база как есть (develop de981d5, виды `runs/typed_1111`, тикеты `docs/tickets_1106k`). За модель
  ходит агент Claude Code на Opus через почтовый ящик (`probes/1111/hand/`): один вызов на ход, поле `say` — протокол
  («что сказал прошлый ответ и зачем этот вызов»). Лимиты базы: bash 25, три хода после, окно по оценке знаков.
- **Входы.** Пять из разных клеток [ST3](../1110/ST3-input-map.md), по одной сессии: 01 (App, условие над историей,
  keep 8), 05 (App, текст промпта, keep нет), 06 (ALF, прямая починка, keep 3), 08 (ALF, условие над историей,
  keep 28), 09 (App, починка не названа, keep нет). Теги `o01`, `o05`, `o06`, `o08`, `o09`.
- **Чем отличается от писателя, кроме модели.** Агент видит описания инструментов текстом в первом сообщении ящика, а
  не полем `tools`; вызов пишет JSON-ом в heredoc; у него есть свои инструменты Claude Code (просьба — работать только
  через ящик; проверяется по его отчёту, не механикой); системный промпт Claude Code и пользовательские настройки
  ему видны, журналов и входов 9B в задании нет. Температура и рассуждение — как у агента, не как у базы.
- **Цена (до запуска).** Сессия — до 25 bash с выводом до 8000 знаков и 3–8 правок: к концу около 40–60 тыс. токенов
  разговора плюс обвязка агента; около 35 ходов × средний контекст 50 тыс. ≈ 1,5–2 млн входных токенов, почти все из
  кэша, и 10–20 тыс. выходных. Пять сессий — впятеро. Подписка, не API.
