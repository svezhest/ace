# RL — в сводке повтора строка «-»: что было в логе на месте расхождения

[Указатель проб](../INDEX.md) · хронология: [11.11](../days/1111.md) · повод: [N27](N27-base-27b-thinking.md)

- **Повод.** Две сессии 27B с рассуждением споткнулись об одно место сводки `tests/rerun.py` после правки. Сводка
  печатает только новое сообщение («+ user: …») и не показывает, что стояло в логе на этом месте:
  - t5, ход 11: «wait, run 3 had 0 re-runs in my analysis!» — в удачном run 3 новое сообщение заменило прежнее сообщение
    той же защиты (повтор прошлого шага, он и в логе не исполнялся), а в удачных 8 и 20 — ответ среды `Output: …`
    (повтор в логе исполнился и дал данные). В сводке эти три случая — одна строка. Итог сессии: «the model in the log
    recovered on its own» — неверное чтение.
  - t3 (докат), ходы 24–25: оба оставшихся хода без bash ушли на вопрос «почему расходится run 3» и на вызовы bash,
    которого уже нет (`python3 tests/rerun.py 3` показал бы обе строки).
- **Пробовали ли.** В указателе и днях строки «-» в сводке нет. Близкое: G2 (одна строка-факт в ответе проверки, 5 → 10
  из 10), 10.11 «какой вызов у какого прогона». В подробном выводе (`rerun.py N`) строка «-» есть с самого начала.
- **Изменение (одно).** Ветка `feature/rerun-log-line`, `editor/rerun.py`: в сводке перед «+» идут строки «-» — первое
  сообщение лога на месте расхождения, по строке на прогон (удачные первыми, не больше 5, по 110 знаков); если у всех
  прогонов группы оно одно — одна строка без номеров. Группировка прежняя. Форма — обычный diff.
- **Замер.** Развилка записанной сессии (`editor/fork.py --last`): тот же ход, ответ проверки с новой сводкой
  (`probes/1111/rl/mk.py`). Стенд think27, температура 0 — одна попытка на точку; база — записанный ход.
  Проверка прибора: развилка t5 без замены должна повторить записанный ход 11 слово в слово.
  - t3 (докат), ход 24 (хвост без bash). Записано: «I'm quite confused…», вызов bash, которого нет.
  - t5, ход 11. Записано: условие не тронуто, в сообщение дописан совет про неопределённое имя.
- **Ожидание (до запуска, 17:14 по `date`).**
  - t3, ход 24: назовёт расхождение run 3 заменой текста прежней защиты и bash не вызовет. Не сбылось, если снова
    пойдёт выяснять run 3.
  - t5, ход 11: один к двум, что условие сузит. Против: решение «blocking them costs one step each» принято до правки
    со знанием, что повтор законный, и проверка по тикету отвечает Ok по run 8. За: теперь видно значение — в логе
    повтор дал `Output: 17` и список будильников. Не сбылось в любом случае, если run 3 снова назван загадкой.
- **Не проверяется здесь.** 9B; виды ALF (там в группе до 15 прогонов — длина сводки); сессия целиком (развилка — один
  ход); задевает ли строка «-» прежние записанные сессии (проигрыш gold — до влития в develop).
- **Итог первой формы («-» / «+»), 17:46 по `date`.** Три развилки, `runs/n27_1111/rl/`, 17:14–17:45.
  - Прибор: развилка t5 без замены повторила записанный ход 11 слово в слово (текст и аргументы edit) — сравнение с
    записью законно.
  - t3, ход 24. Bash не вызван, ход потрачен на правку: возвращена исходная проверка «тот же код, что на прошлом шаге»
    с прежним текстом, новая («код уже исполнился успешно») поставлена второй. С такой правкой run 3 шёл бы как в логе.
    Но прочитано неверно: «my new check doesn't fire for a repeat of a *failed* step» — новая проверка там как раз
    сработала (строка «+» это показывает), изменился только текст. Ожидание сбылось по действию, не сбылось по чтению.
  - t5, ход 11. Условие не сужено (ожидал этого два к одному). В рассуждении (19,6 тыс. знаков) слов «Output», «17»,
    «alarm», «passed» нет ни разу: строки «-» не использованы. Десять раз повторено «the observation explicitly asks
    for this behavior». Run 3 загадкой не назван. Ход ушёл на bash (`sed` и `rerun.py 1`).
- **Что это значит.** Строка «-» в виде diff на 27B — полдела: там, где писатель и так искал причину (t3), она
  заменила два потерянных хода правкой, но причину он вывел неверно; там, где не искал (t5), она не прочитана. Diff
  требует самому вывести, что шаг теперь не исполняется. Автор (17:3x): «модель такая: и что? … ей нужно прямо сказать
  что да как»; про ярлык «only the harness's own message is reworded» — «what the hell does it mean».
