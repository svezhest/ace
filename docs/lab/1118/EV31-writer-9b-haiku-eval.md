  думать». Оценщик — Haiku (автор: «поставь в очередь писатель 9б и хайку»).

  `stand9p.sh` — как в EV27.
- **Серии.** 10 входов EV27 × seed 1: `h9n` (`default`) и `h9t` (`thinking`). 3 потока, пара NT → T одного входа — в
  одном потоке. Скрипт — `runs/evw_1113/night_9b_h.sh`, старт — по `GPU_FREE.txt` llm-81.
- **Мерка.** Как EV27: итоговый src глазами по diff против входа (Ok / спорно / F), по критериям O4-writer-labels с
  поправкой EV29. Вердикт Haiku на итоге против метки; число check.

  - Check за сессию у `h9n` меньше, чем в EV27 (25 на 10). Ложных Failed у Haiku меньше, чем у 9B T.
  - Серия займёт 3–4 ч: префилла оценщика на GPU больше нет.
