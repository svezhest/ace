### TKC: покрытие изменённых строк в проверке по тикету (6.11, 05:45)
- **Точки трения TK/TKS**, по которым сделана проба:
  - на Failed писатель не верит прибору: придумывает ограничения rerun (4 случая);
  - главный брак — условие, которое на данных никогда не истинно: 08_IO, 00_TK, ключ `ctx["raw"]` на 06. Ответ «как в логе» говорит, что правка ничего не изменила, но не говорит, где именно она ничего не делает.
- **Гипотеза.** Если после строки проверки показать, сколько раз выполнилась каждая изменённая строка в прогоне тикета, писатель увидит «`if` — 50 раз, тело — ни разу». Тогда он будет искать причину в своём условии, а не в rerun.
  - Это стандартная форма (как coverage annotate): только факты проигрыша, без правил и без наводки на ошибку.
- **Механика.**
  - `editor/rerun.py --json --cover`: `sys.settrace` на файлы src во время `harness.run`, счётчик по строкам. Шаги `<genexpr>` не считаются.
  - `gate._changed_lines`: строки .py, изменённые или новые против вида (difflib), пересечённые со строками кода функций. Уровень модуля (def, импорт, константы) выполняется при импорте и не считается.
  - `gate._cover_lines`: подряд идущие строки с одним счётчиком сливаются в одну строку вывода, не больше 14 строк вывода.
  - Флаг `--ticket-cover` (только с `--ticket`). Отрезок проигрыша указан явно: «to the end of the log» или «up to model call K, where it goes differently».
- **Проверено на готовых сессиях** (`scratchpad b1/tc_test.py`):
  - 08_IO: `if any(o and o in set(recent) …)` — 70 раз, `return {` — ни разу;
  - 00_TK: `if in_cycle(history)` — 50, тело — ни разу;
  - 06_TK: условие — 50, тело — ни разу;
  - 01_TKS (Ok): `repeats_cycle` — 17, сообщение — 1.
  - Вывод `--dry` с флагом и без совпадает байт в байт (md5 b149f0cb…).
- **Побочный эффект:** `tests/rerun_core.py` у писателя — копия `editor/rerun.py`, так что в нём появился ключ `--cover`. Сессии TKS_s2, начатые после правки (04–09), видят этот ключ. Поведение без ключа то же.
- **Сессии `wv_NN_TKC`:** TKS (`--ticket-show`) + `--ticket-cover`, seed 1, в очереди вперемешку с TKS_s2. Сравнение — TKS s1.
- **Мерки:**
  - что делает после Failed: правит условие / не верит прибору / finish;
  - V/P/B/x руками.

**Главное: покрытие не читается.**
- В 10 сессиях, где писатель видел строки «ran N times / never ran / returned False», он **ни разу** на них не сослался: 0 упоминаний «never ran», «returned», «ran N times» в его ответах и рассуждениях после показа.
- Строку Failed он замечает примерно в половине случаев: в двух ходах после Failed есть «as in the log / changes nothing / no changes / crash»:
  - TK — 8 из 18;
  - TKS — 3 из 9;
  - TKC — 3 из 7;
  - TKR — 3 из 4.
- Значит, факт «где правка мертва» доходит до писателя, только если он сам его ищет. Вывод после правки он читает выборочно: первую строку и общую сводку rerun, а блок ниже пропускает.
- **Это меняет план.** Растить содержание проверки бесполезно, пока её не читают. Точка трения — внимание к выводу, а не его полнота.
- TKF (проверка первой) — первая проба на это, она в очереди.
- Если и TKF не даст ссылок на покрытие, следующая ступень — **короче, а не длиннее:** одна строка с самым важным фактом вместо таблицы. Например: «Failed: run 6 goes exactly as in the log; your `if in_cycle(history):` at harness.py:193 ran 50 times and was never true». Это тот же факт из покрытия, просто в строке, которую он читает.

# nrhsi/editor/gate.py:541-564
def _cover_lines(changed, cov, d):
    """Строки правки со счётчиками в одном прогоне: подряд идущие с одним счётчиком — одной строкой."""
    upto = ("to the end of the log" if d is None else
            "up to model call %s, where it goes differently" % d["call"] if d.get("call") else "until it stops")
    res = []
    ret = (cov.get("__ret__") or {}) if getattr(C, "TICKET_RET", False) else {}
    for rel, (lines, text) in sorted(changed.items()):
        hits = {int(k): v for k, v in (cov.get(rel) or {}).items()}
        rets = {int(k): v for k, v in (ret.get(rel) or {}).items()}
        groups = []
        for ln in lines:
            n = hits.get(ln, 0)
            if groups and groups[-1][2] == n and not rets.get(ln) and not rets.get(groups[-1][1]) and groups[-1][1] == ln - 1 - sum(1 for k in range(groups[-1][1] + 1, ln) if k in lines):
                groups[-1][1] = ln
            else:
                groups.append([ln, ln, n])
        for a, b, n in groups:
            where = f"src/{rel}:{a}" + (f"-{b}" if b != a else "")
            rv = rets.get(b) if text[b - 1].strip().startswith("return") else None
            got = (" -> returned " + ", ".join(f"{k} {'once' if m == 1 else f'{m} times'}" for k, m in sorted(rv.items(), key=lambda kv: -kv[1])[:3])) if rv else ""
            res.append(f"  {where}  {'never ran' if n == 0 else 'ran once' if n == 1 else f'ran {n} times'}:  {text[a - 1].strip()[:90]}{got}")
    if len(res) > 14:
        res = res[:13] + [f"  ... {len(res) - 13} more groups of changed lines"]
    return upto, res
