# ST1 — детерминизм сессии и воспроизведение хода развилкой (тикет 10.11, шаги 1 и 2)

[Указатель проб](../INDEX.md) · хронология: [10.11](../days/1110.md) · тикет: [TICKET-1110-writer](../../TICKET-1110-writer.md)

- **Гипотеза.** Сессия с одним seed повторяется дословно; `editor/fork.py` с seed записанного хода даёт записанный
  ответ. Без этого разницу в 2–5 ответов из 10 нельзя отличить от шума прибора.
- **Пробовали ли.** Нет. В REPORT-1106 (раздел 4) названы три посторонних источника расхождения: время файлов копии,
  порядок `set` в `python3` песочницы, копия ядра повтора. Первые два закреплены 6.11 (`WORK_MTIME`,
  `PYTHONHASHSEED=0`), третий — [ST1 ядро](ST1-rerun-core.md).
- **Изменение и коммит.** Кода нет. База 076d37a, вход 08 с тикетом (`probes/1110/args08_now.sh`), seed 1.
  Четыре сессии разом: по две на стенд default и thinking (scratch `fk/det/run.sh`). Потом
  `probes/1110/forkcheck_repro.py LOG СТЕНД ХОДЫ` — по одному запросу на ход.
- **Мерка.** Записи логов двух сессий без времени, пути копии и `usage`; итоговый diff; у воспроизведения — текст,
  рассуждение, вызовы и число токенов ответа.
- **Ожидание до замера (18:58).** default — совпадут; thinking — совпадут, но уверенности меньше (≈ 70 %).
- **Итог (10.11, 19:15 по `date`).**

  | стенд | ходов | записи логов | итоговый diff | модель, мин | с на ход |

  ставит сама, на запрос не влияют.
- **Закреплено по ходу.** Время файла в заголовке итогового diff убрано (`work.diff_src`): модель его не видела,
  но две одинаковые сессии давали разные файлы.
- **Что это даёт.** Пара сессий с одним seed расходится только там, где разошёлся вход. Сравнение «тот же префикс,
  тот же seed, одно изменение» — чистое; его и брать меркой на развилках.
- **Цена (для расчёта проб).** Сессия: default ≈ 9 мин, thinking ≈ 17 мин модели при четырёх потоках. Один ответ
  на развилке: default ≈ 20–25 с, thinking ≈ 50 с в среднем, до 3 мин на ходе правки.
- **Побочное наблюдение (к шагу 8).** В сессии default ходы 15–21: проверка верно сообщила
  `TypeError: set.pop() takes no arguments (2 given)`; писатель решил, что это «stale .pyc», потом что «checker is
  reading a different file path», и потратил на это 5 вызовов bash. Свою проверку `s={}; s.pop("a", None)` он сделал
  на словаре, а не на множестве. Прибор здесь не врал.
- **Не проверено.** Один вход, один seed, по одной паре на стенд. Повтор через перезапуск шлюза и воркера не делал:
  записанные 10.11 до этой пробы сессии не воспроизводил.
