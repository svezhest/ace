# ST1 — снимок базы и инвариант чистки (тикет 10.11, шаг 1)

[Указатель проб](../INDEX.md) · хронология: [10.11](../days/1110.md) · тикет: [TICKET-1110-writer](../../TICKET-1110-writer.md)

Не проба, а опись прибора: что считается базой и чем проверяется, что чистка кода её не меняет.

- **Снимок.** `docs/base/4420356/` — всё, что модель получает до первого хода, файлами: `system.txt` (один для обоих
  бенчей), `first.NN.txt` (первое сообщение входа NN с тикетом; для 00 и 08 ещё и без тикета), `README.alf.md`,
  `README.app.md` и `tree.*.txt` (README и состав копии; у видов одного бенча совпадают — проверено), `tools.json`
  (описания инструментов), `MANIFEST` (sha256). Сборка — `probes/1110/base/snap.py OUT`, модель не вызывается.
  Входы `runs/typed_1110/in/` лежат вне git; в снимке их текст теперь есть.
- **Сверка снимка.** 30 из 30: `system + first` снимка равны выводу `--dry` на 10 входах в трёх проигрышах
  (до чистки, после чистки, после одного ядра).
- **Инвариант чистки.** `probes/1110/gold/gold.sh new NAME` + `editor/replay_cmp.py`: 42 записанные сессии
  проигрываются без модели, сравниваются логи, копии и diff. В этих сессиях 72 правки, применено 32; формы ответа
  проверки по тикету, которые проигрыш покрывает:

  | ответ проверки | сколько |
  |---|---|
  | Failed по тикету («no effect in run N») + Ok по keep | 9 |
  | Ok по тикету + Failed по keep («changes run N, which passed») | 8 |
  | Ok + Ok | 6 (control) и 2 (prompt) |
  | оба Failed: харнесс падает (AttributeError, NameError, IndexError) | 5 |
  | оба Failed: без эффекта и keep задет | 1 |
  | Ok без keep | 1 |

  Тикет просил три записанные правки (Ok, Failed по тикету, Failed по keep) — покрыто с запасом.
- **Дыра, найденная при сверке.** В мету сессии писались только имена инструментов, не описания: проигрыши и `--dry`
  описаний не видят. Сверено отдельно: схемы bash, edit, finish на 951bc3b (до чистки, флаги базы) и сейчас равны.
  С 076d37a в мету пишется `tool_schemas`.
- **Чего проигрыш не покрывает.** Конец по окну и по бюджету вызовов; вход `--input` — 2 сессии из 42; ворота finish
  сняты только в [ST1 один Python](ST1-one-python.md).
