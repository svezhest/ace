# ST7 D1 — первое действие: на что уходят первые три хода (тикет 10.11, шаг 7)

[Указатель проб](../INDEX.md) · хронология: [10.11](../days/1110.md) · тикет: [TICKET-1110-writer](../../TICKET-1110-writer.md)

Разбор без модели, 10.11, 21:19 по `date`. Данные — 40 прокатов базы на три хода из [ST6V](ST6V-setup-variants.md)
(`runs/fk_1110/s6/0/`, входы 05, 06, 08, 09, default). Счёт — `probes/1110/s6/d1.py`: команда режется на части по
`;`, `&&`, `||`, часть относится к первому подходящему классу.

- **Мерка тикета — первые три вызова против пути свежего агента (шаг 4).** Пути нет: шаг 4 ждёт подтверждения
  автора. Ниже — только опись того, что делает база.
- **Сколько вызовов bash уходит за три хода** (из 25): 05 — 3–6, 06 — 6–11, 08 — 6–9, 09 — 4–10. В одном ходу модель
  шлёт несколько вызовов разом, каждый считается.

| части команд, 10 сессий | 05 | 06 | 08 | 09 |
|---|---|---|---|---|
| README | 9 | 10 | 10 | 11 |
| файл, названный во входе | 23 | 40 | 20 | 28 |
| лог, названный во входе | 3 | 15 | 7 | 4 |
| другой файл `src/` | 7 | 9 | 29 | 21 |
| чтение исходников `tests/` | 0 | 27 | 9 | 9 |

| запуск `tests/rerun.py`, `runs.py`, `smoke.py` | 4 | 1 | 0 | 4 |

- **Что видно.**
  - README первым — 39 из 40; системный промпт отправляет туда первой строкой. Без README вывод повтора не
    прочитать, так что это не лишний ход.
  - Названные файлы читают целиком (34 из 40 сессий). В ALF это 25–170 строк, чтение целиком уместно; в App промпт
    на 350 строк на входе 05 читают по названным строкам.
  - «Другой файл `src/`» на входе 08 — в основном `hook_types.py` и промпты. `hook_types.py` во входе 08 не назван,
    а без него форму `Step` не узнать: это нужное чтение, а не обзор.
  - **Лишнее — чтение исходников `tests/`** (`cat tests/rerun.py`, `tests/rerun_core.py`, `tests/smoke.py`): 45
    частей из 373, больше всего на 06. Что делает повтор, сказано в README; исходник мерки писателю не нужен.
    К какой строке постановки это привязано — не нашёл: ни промпт, ни README читать `tests/` не велят. Возможная
    причина — «This directory is everything there is to read» в первой строке промпта; не проверено.
  - Запуск повтора в первых трёх ходах — 5 сессий из 40: прогон из наблюдения читают глазами по логу, а не через
    `tests/runs.py steps N`, который в README назван.
- **Почему дальше D1 сейчас не двигаю.** Эталонного пути нет (шаг 4). Преобладающее действие — README и названные
  файлы — совпадает с тем, что нужно. Изменение, которое я мог бы пробовать (убрать повод читать `tests/`), меняет
  2–4 вызова из 25 и на замысел не действует; пробовать его раньше D2 значит чинить мелочь раньше главного.
  Варианты постановки на первые ходы не подействовали, кроме вредного C ([ST6V](ST6V-setup-variants.md)).
