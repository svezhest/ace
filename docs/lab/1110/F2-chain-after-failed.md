## 10.11, 05:15 — проба F2: цепочка ходов после Failed (g7_r0, thinking)

- **Гипотеза.** При верном замысле и мёртвом коде писателю с рассуждением хватает нескольких ходов «правка — проверка»,
  чтобы дойти до Ok/Ok: каждая проверка возвращает Failed со значениями.
- **Пробовали ли.** G4 — хвост 10 на default с первой правки любого замысла (не помог). Здесь старт с верного замысла
  и thinking; F1 — один ход.
- **Изменение.** Кода нет. `roll.py` с g7_r0 ход 21, 10 продолжений, до 6 ходов, `--stop end`, стенд thinking; у
  каждого своя копия вида, правки применяются и проверяются. Bash кончился до развилки.
- **Мерка.** Глазами: на каком ходе тикет Ok по run 40 и Ok по run 28; итоговый код.
- **Ожидание (до замера, записано через минуту после старта, результатов не видел).** Ok/Ok за 6 ходов у 5 из 10;
  Ok по run 40 у 7. Риск: счётчик хвоста не восстановится и сессии кончатся сразу.

## 10.11, 05:28 — F2 прочитана; F2b постановка

- **Механика.** Продолжения получили до 4 ходов (счётчик хвоста после развилки начался заново), 05:15–05:28.
- **Итог.** Ok/Ok у 6 из 10 (#0, #1, #3, #4, #7, #8); прочитал итоговый код всех шести — точно: чередование в последних
  пяти шагах → Hint, run 28 не тронут. Ok по run 40 у 8 из 10 (#2 и #6 задевают run 28). Мимо 2: #9 (после Failed по
  run 28 сузил до мёртвого), #5 (`finish` без правки со словами «the wiring now works» при Failed).
- **Ожидание сбылось:** ждал Ok/Ok 5, Ok по run 40 — 7.
- **Сколько ходов понадобилось:** с первой правки 3 (#1, #4, #7), #8 — тоже с первой, со второй-четвёртой — #0 и #3
  (через падение `IndexError` и через Failed по run 28). Одного хода хватило 4 из 10 — сходится с F1 (4 из 10).
- **Вывод.** Сессия G7 #0, записанная как «мимо», при 2–4 ходах после первой проверки даёт точную правку в 6 из 10.
  В G7 у пяти поздних сессий этих ходов не было. Узкое место на thinking — число проверенных правок после первой, а
  не замысел. На default то же не работало (G4: хвост 10, точно 2 из 10) — там мимо был сам замысел.
- **Не проверено.** Одна развилка, и на ней значения в Failed были по делу; полные сессии с длинным хвостом на thinking.

**Код и запуск F2** (приписано 10.11).

