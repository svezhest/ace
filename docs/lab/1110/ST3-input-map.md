**Можно ли сделать точную правку, не читая ничего сверх названных строк.** `edit` требует дословный `old_string`,
поэтому одно чтение названных строк нужно всегда; вопрос — хватает ли его.
- **Да: 02, 06, 07.** Вход называет и место, и починку. Чтение эти входы не проверяют: на них видно только запись.
- **Наивная — да, точная — нет: 01, 04.** Правку «сравнить ещё и с `steps[-2]`» можно написать по входу; не задеть
  удачный run 8 — только посмотрев, чем он отличается.
- **Нет: 00, 03, 08** (нужна форма данных и условие), **05** (нужен факт о примере), **09** (починка не названа).
