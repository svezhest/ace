# ST1 — один Python в ответе на правку (тикет 10.11, шаг 1)

[Указатель проб](../INDEX.md) · хронология: [10.11](../days/1110.md) · тикет: [TICKET-1110-writer](../../TICKET-1110-writer.md)

- **Гипотеза.** На правку с синтаксисом новее Python песочницы три проверки в одном ответе (smoke, rerun, тикет)
  должны сказать одно.
- **Пробовали ли.** Расхождение замечено в серии TY ([TY](TY-typed-hooks.md)); пробы не было.
- **Что есть на стенде (по живым файлам, не по памяти).** Интерпретаторов три:

  | где | версия | что под ним идёт |
  |---|---|---|
  | песочница писателя, `nrhsi/bin/python3` → CommandLineTools | 3.9.6 | `python3` в bash, smoke, rerun, с 4420356 — проверка по тикету |
  | харнесс писателя (`python3 -m nrhsi.editor`) | 3.14.0 | отказ edit по синтаксису (`edit.check_syntax`), pyflakes, разбор условия для показа значений |
  | окружения бенчей, `alfworld/.venv`, `appworld/.venv` | 3.11.11 | настоящий запуск агента на `src/` |

- **Изменение и коммит.** 4420356: проверка по тикету — под `python3` песочницы. Проба —
  `probes/1110/onepy/onepy.py` (4df895d): две правки `src/hooks.py` на входе 08 проигрываются без модели.
- **Мерка.** Глазами: что говорит каждая строка ответа на правку.
- **Ожидание до замера.** После 4420356 smoke, rerun и тикет говорят одно; отказ edit и pyflakes такую правку пропустят.
- **Итог (10.11, между 18:48 и 18:58 по `date`).**

  | правка | отказ edit, pyflakes (3.14) | smoke (3.9) | rerun (3.9) | тикет (3.9) |
  |---|---|---|---|---|
  | оператор `match` | пропущено | `SyntaxError: invalid syntax` | то же | «Failed: in run 40 the harness crashes: SyntaxError…» у обоих прогонов |
  | аннотация `-> Hint \| None` | пропущено | `TypeError: unsupported operand type(s) for \|` | то же | «Failed: … crashes: TypeError…» у обоих |

  Три проверки, которые исполняют `src/`, согласны. Заодно впервые снят ответ ворот finish «Not finished yet» — в
  проигрышах чистки его не было.
- **Что осталось и почему не тронуто.**
  - Отказ edit и pyflakes идут под 3.14. В 2391 записанной правке (wvar_1104, q1, fk_1110) нет ни одной, где это
    проявилось: 22 отказа по синтаксису, после применённых правок — ни одного `SyntaxError` и ни одного `TypeError` от
    `|`. Перевод их на 3.9 ухудшил бы тексты отказов: «expected ':'», «expected an indented block after 'if' statement
    on line 168» — это сообщения 3.10+, в 3.9 на их месте «invalid syntax».
  - **Песочница строже настоящего запуска.** Обе правки пробы верны под 3.11, под которым идёт агент, а писателю на
    них отвечают «crashes». Версию Python промпт не называет («python3 is available»).
- **Вопрос автору.** Перевести `nrhsi/bin/python3` на 3.11.11 окружений бенчей? Тогда проверки писателя идут под тем же
  Python, что и агент. Цена: меняется вывод `python3` в bash (трассы 3.11 длиннее) и песочница ревьювера — она общая.
- **Не проверено.** Как часто 9B пишет синтаксис 3.10+: в записанных сессиях ноль, но входы с типами (TY) на живых
  сессиях почти не шли.
