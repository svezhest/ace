# Указатель проб

Одна строка на файл пробы. Всё в строке взято из самой записи: гипотеза — словами записи или её ожиданием, итог — числом
из записи. Где записи нечего сказать, так и написано. Коммиты, которых в записи нет, взяты из `docs/CODE-MAP-1110.md` и
помечены «(CODE-MAP)». Каталоги данных — относительно корня репозитория; `fk/` в записях 10.11 — это `runs/fk_1110/`,
`mp/` в записях 9.11 — `runs/mp_1109/`.

Хронология по дням — [days/](days/); как устроены файлы — [README](README.md); старые номера строк — [OLD-LINES](OLD-LINES.md).

**Статусы:** замерена — итог в записи есть; промежуточный итог — окончательного нет; замер испорчен — запись сама
называет замер недействительным или мерку негодной; снята — в записи снята до замера; не запускалась — постановка есть,
сессий нет; итога нет — постановка есть, про запуск и итог в журнале ничего; разбор — чтение готовых данных без новых
сессий модели. «В базе» — флаг остался в базе писателя (по CODE-MAP).

V/P/B/x — верная / правдоподобная (промпт) / широкая / брак, на 10 сессий, если не сказано иное.
