# EV26 — подача автора против EV6a на всём размеченном наборе, выбор одной

[Указатель проб](../INDEX.md) · тема: [оценщик](../../writer.evaluator.md) · прежние: [EV20](../1114/EV20-author-layout-on-writer.md),
[EV25](../1116/EV25-author-layout-on-ev6a-misses.md), разметка — [O4-writer-labels](../1116/O4-writer-labels.md)

- **Повод.** Автор (17.11): «до ума доведи сравнение моей подачи и 6а. и уже выберем одну. а потом замеры 9б т, 9б нт».
  В EV25 подача автора выиграла на 3 правках из 8, но набор состоял из одних провалов EV6a. В EV20 сравнение
  снято на q5, а не на нынешнем стенде. Здесь обе подачи прогоняются на одном стенде по всему набору с разметкой.
- **Набор.** 64 правки с меткой (спорные не берутся):
  - 20 из EV20 (итоги писателя EV15/EV16): F 9, Ok 11;
  - 44 итоговых src писателя на oQ4e (база / EV21 / EV23): F 12, Ok 32, метки из O4-writer-labels.

  8 из них уже сняты в EV25. Остальные 56 гонит `probes/1117/ev26.sh`: сначала сборка входов без модели, затем вызовы
  парами (v2 → ev6a на каждом теге). Ответы пишутся в те же `runs/evw_1113/ev25_<var>_plain27.jsonl`.
- **Стенд.** Тот же, что в EV25: oQ4e нового рецепта (q8 KV, `QWEN_DRAFT=auto`, llm 2df454b), 27B `plain27`, T=0, без
  рассуждения, `prompt_cache=read`.
- **Ожидание (17.11, 16:40 по `date`, до запуска).**
  - `ev6a` ≈ 53 из 64 (±3). Довод: в сессиях писателя оценщик ошибся на 8 из 44 итоговых src (7 пропусков, 1 ложный
    Failed), на EV20-наборе на старом oQ4e — на 3 из 20 (EV22), а в EV25 новый стенд не сдвинул ни одного вердикта.
  - `v2` = `ev6a` ± 3, скорее на 1–3 выше: три ложных Failed из EV25 уже в её пользу. Пропуски F (мёртвая ветка 03,
    `continue` 06, 14 — «харнесс не видит») жду общими, как в EV20 и EV25.
- **Правило выбора (записано до запуска).**
  - Беру `v2`, если она верна на ≥ 2 правки больше и при этом теряет не больше одного F, который ловит `ev6a`.
  - Беру `ev6a`, если разница меньше 2 правок: её вход в 1,2–2,3 раза короче, а в сессии писателя каждая проверка
    добавляет префилл (половина времени стенда — префилл, замер 16.11). Доводы читаю до счёта.
  - Решает автор; правило — моё предложение.
