# RV1 — разметка находок 9B T на видах App (ручная, по `eval/key/`)

Метки: **true** (совпадает с ключом, верный механизм) / **false** (противоречит логам или src) / **demo** (демо из промпта
принято за эпизод) / **trusted** (слова агента как факт) / **incomplete** (направление верное, без решающего места или
механизма) / **model** (верно о модели, о харнессе ничего) / **junk** (заметки о ходе работы, описание кода).

на успешном шаге), 19 (B5 отказ без шага -> контекст); r4-6-7-12-18 — 4, 6, 12 (B9), 7 (круг A↔B).
