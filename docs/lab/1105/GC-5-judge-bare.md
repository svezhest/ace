## Проба GC-5: судья видит код без комментариев (05.11)
- Гипотеза: слепое место 2 (вера описанию). Если в diff для судьи нет комментариев и docstring, он судит по коду и месту, а не по заявлению правки.
- Флаг judge2 `--bare` (коммит в thin, см. git log): diff .py считается между копиями без строк-комментариев и docstring; .md как есть. Вариант «no effect» (у него больше хороших).
- Мерка: 27 правок GC + judgeset (12). Хорошие приняты / плохие отвергнуты против --three без --bare. Ожидание: 00_s2, 01_s3, 04_s3 отвергнуты, хорошие не теряются. Правки промпта (слепое место 1) — без изменений: эта проба их не касается.
  - Сухой прогон 00_GC_s2 с --bare: diff 15 строк вместо docstring на абзац. В коде видна причина обрыва: при 3 действиях одна группа равна сама себе, и `stalled` истинна на 3-м шаге. Отладка: первая версия обнуляла файл до чтения (`open(p, "w")` раньше `read`), исправлено до запуска.
  - Задания jg5_* (25 правок GC, которые судья видит, + 12 judgeset).
- **Итог GC-5** (103 мин модели), с «no effect»:

  | | хорошие приняты | плохие отвергнуты |
  |---|---|---|
  | GC без --bare | 9/9 | 9/16 |
  | GC с --bare | 8/9 | 9/16 |
  | judgeset без --bare | 5/6 | 5/6 |
  | judgeset с --bare | 5/6 | 4/6 |

  - Исправились 00_GC_s2 и 01_GC_s3. Сломались 03_GC_s6 (V отвергнута), 06_W1 (V отвергнута), 01_GC_s2, 02_GC_s1, 04_W2 (B приняты). Чистый итог около нуля.
  - Правки только промпта получили тот же вход и тот же seed, поэтому вердикты с ними совпали знак в знак (seed детерминирован).
  - Из правок кода решение сменилось у 8 из ~25. Гипотеза «вера описанию» как главная причина не подтверждена. Похоже на шум судьи на уровне правки (3 сэмпла × ≤4 прогона).
